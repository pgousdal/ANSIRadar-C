# Changelog

## 0.2.0

- Added native Linux Mystic DOOR32.SYS type 2 descriptor/socket runtime.
- Added shared local/socket transports, bounded input decoding, time-left handling, and socketpair tests.

## 0.1.0

- Established the standalone C edition extracted from ANSIRadar.
- Added the C99 core and fixed 80x25 rendering.
- Added ANSI/CP437 support and an ASCII character profile.
- Added aspect-correct polar radar projection.
- Added deterministic aircraft ordering and collision behavior.
- Added source refresh pacing and stale-source indication.
- Preserved core, renderer, provider, and fixture test coverage.
- Supported both Makefile and CMake builds.

Earlier commits originated in the ANSIRadar monorepo before this repository split.
