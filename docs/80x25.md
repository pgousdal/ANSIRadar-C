# 80x25 Display

The display is always 80 columns by 25 rows, matching classic ANSI/CP437 BBS terminals. The radar uses an elliptical projection so equal-distance rings appear visually circular on a character-cell display. The header occupies row 1, the radar occupies the upper screen, the aircraft table and source status occupy the lower rows, and controls are shown on row 25.

## Character Profiles

`--charset cp437` uses line and radar glyphs suitable for CP437 terminals. `--charset ascii` uses plain ASCII alternatives for terminals that cannot display the extended character set. ANSI cursor positioning and optional color are independent of the character profile.

## Ordering and Collisions

Aircraft are ordered deterministically by range by default, with alternate table sort modes available interactively. When multiple aircraft project to one cell, selected aircraft win first, followed by aircraft with callsigns, nearer aircraft, fresher observations, and finally lexical ICAO order. This makes both live updates and `--once` fixture renders stable.
